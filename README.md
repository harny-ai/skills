# Harny skills

Harny gives each person who uses an app a private memory the app's AI can read, and lets an agent act for that person inside permissions the app owner sets.

This repo holds a skill that shows your coding agent how to add Harny to an app.

## Install

Claude Code plugin marketplace:

```
/plugin marketplace add harny-ai/skills
/plugin install harny-memory@harny
```

Skills CLI, or any tool that copies a skill folder:

```
npx skills add https://github.com/harny-ai/skills
```

Documentation: [Quickstart](https://harny.ai/docs/memory-api/quickstart) · [harny.ai](https://harny.ai)
